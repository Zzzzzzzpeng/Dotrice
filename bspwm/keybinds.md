
# 🧠 bspwm Keybinds

## 🚀 Apps

* `Super + Enter` → Kitty terminal
* `Super + Space` → Rofi launcher
* `Super + B` → Vivaldi
* `Super + M` → Spotify
* `Super + P` → Pavucontrol
* `Super + W` → Whatsie
* `Super + N` → Netflix
* `Super + Y` → Yazi
* `Super + O` → Obsidian
* `Super + Z` → Zathura
* `Super + V` → Vesktop

## 🗂️ Workspaces

* `Super + ← / →` → Previous / next workspace
* `Super + 1–6` → Jump to workspace
* `Ctrl + Shift + 1–6` → Move window to workspace
* `Ctrl + Alt + ← / →` → Move window prev / next workspace

## 🪟 Windows

* `Super + Q` → Close window
* `Super + Shift + Q` → Kill window 💀
* `Super + /` → Toggle layout
* `Super + G` → Swap with biggest window

## 🎛️ Window State

* `Alt + A` → Floating
* `Alt + F` → Fullscreen
* `Alt + T` → Tiled

## 🖥️ bspwm

* `Super + Alt + Q` → Quit bspwm
* `Super + Alt + R` → Restart bspwm
* `Super + Esc` → Reload sxhkd 🔄

## 📸 Screenshots

* `Super + Alt + A` → Area screenshot
* `Super + Alt + S` → Full screenshot
* `Super + Alt + D` → Delayed screenshot

## ⚡ Power

* `Ctrl + Super + Alt + Q` → Log out
* `Ctrl + Super + Alt + R` → Reboot
* `Ctrl + Super + Alt + P` → Power off
* `Ctrl + Super + Alt + L` → Lock screen 🔒

## 💀 Emergency

* `Super + Alt + K` → Kill frozen app
